3 · Scores vs. loadings

Two words, two different objects.

Scores belong to observations

A score is an observation's coordinate after projection onto a principal component.

Loadings belong to variables

A loading describes how strongly an original variable contributes to the component direction.

Memory trick:
Scores = samples.
Loadings = variables.

The sign of an entire PCA axis can flip without changing the underlying solution.

4 · Scaling changes the question
